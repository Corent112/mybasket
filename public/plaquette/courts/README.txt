MYBASKET - TERRAINS PLAQUETTE

Terrain MyBasket par défaut :
  public/plaquette/courts/default/demi.jpg
  public/plaquette/courts/default/complet.jpg

Nouveaux terrains prédéfinis :
  Créer un dossier dans public/plaquette/courts/presets/
  Exemple :
    public/plaquette/courts/presets/poitiers/demi.png
    public/plaquette/courts/presets/poitiers/complet.png

Chaque terrain doit toujours avoir 2 images : demi + complet.
Utiliser de préférence PNG haute qualité et garder les mêmes proportions/orientations que les terrains de référence.

Les polices permanentes vont dans :
  public/fonts/
